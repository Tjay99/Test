# Test

Générateur de modèles de CV modernes au format Word (.docx).

## Prérequis

- Python 3.10+

## Installation

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Générer les modèles

```bash
python cv_templates.py --output-dir output_cvs
```

Trois fichiers seront créés dans `output_cvs/`.
